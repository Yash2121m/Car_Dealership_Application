A modern **Flutter-based car dealership application** with AI-powered assistance that helps users browse cars, book test drives, place orders, and manage their profiles — all wrapped in a clean, soft-gradient UI.

---

## 📱 App Overview

This app simulates a **smart car dealership platform** where users can:

* Register & log in securely
* Explore cars by categories and brands
* Book cars and track orders
* Interact with an **AI Car Assistant** for help and recommendations
* Manage their profile and personal details

The UI follows a **minimal + pastel gradient design** with smooth navigation and user-friendly layouts.

---

## ✨ Features

> **Note:** This repository represents the **User-Side Application** of the AI Car Dealer platform.

### 🔐 Authentication

* Login with Email & Password
* User Registration
* Forgot Password flow
* Continue as Guest option

### 🏠 Home Dashboard

* Personalized greeting
* Search cars instantly
* Promotional banners
* Quick actions:

  * Test Drive
  * Orders
  * Wishlist

### 🚘 Car Browsing

* Browse by **Popular Brands**
* View **Most Sold Vehicles**
* Dedicated **Car Categories**:

  * Sedan
  * SUV
  * Coupe
  * Hatchback
  * Convertible

### 🛒 Orders

* View all bookings
* Booking status (Approved)
* Price details for each order
* Booking confirmation flow

### ❤️ Wishlist

* Save favorite cars
* Quick access to shortlisted vehicles

### 🚗 Test Drive

* Book test drives with date & time
* Address selection
* Test drive history with status

### 🔧 Car Maintenance Tracker

* Service reminders
* Insurance renewal tracking
* Pollution check alerts
* Tyre, brake & battery status

### 🔍 Search & Filters

* Search cars instantly
* Filter by:

  * Price range
  * Mileage
  * Brand

### 📊 Compare Cars

* Side-by-side comparison
* Key specs (price, mileage, power, dimensions)

### 💳 EMI Calculator

* Monthly EMI calculation
* Interest rate & tenure sliders

### 📝 Booking Flow

* Document upload (Aadhaar, PAN, Salary Slip)
* Insurance & warranty selection
* Accessories add-ons
* Final price breakdown

## 📄 Resume-Ready Project Description

**AI Car Dealer Mobile Application (Flutter)**
Designed and developed a feature-rich Flutter-based car dealership application enabling users to browse cars, compare models, calculate EMIs, book test drives, purchase vehicles, and manage post-purchase services. Integrated an AI-powered chat assistant for real-time user support and guidance. Implemented complete booking flows including document upload, insurance & warranty selection, accessories add-ons, order tracking, and car maintenance reminders with a modern gradient-based UI.
